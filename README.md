# A3 SOLUC — Site Institucional

Site institucional da **A3 SOLUC — Contabilidade & Soluções Empresariais**, desenvolvido em HTML, CSS e JavaScript puro.

## Versão atual

A versão vigente corresponde ao trabalho consolidado até **29/09/2026 (V11)**.

### Identidade visual
- Fundo preto / dark institucional
- Dourado e prata como cores de destaque
- Logo original A3 SOLUC
- Layout responsivo para desktop e mobile
- Estilo minimalista, profissional e acessível

### Estrutura do site
- Home
- Serviços
- Sobre nós
- Resultados
- Como funciona
- Contato

### Serviços apresentados
- Fiscal
- Contábil
- RH e Departamento Pessoal
- Paralegal e societário
- MEI e pequenos negócios
- Imposto de Renda Pessoa Física (IRPF)

### Diferenciais destacados
- Atendimento rápido, próximo e eficaz
- Construção conjunta da solução com o cliente
- Reuniões de acompanhamento dos processos
- Organização das rotinas e orientação para decisões mais claras
- Bloco “Nosso jeito de atender” dentro da seção Sobre nós

## Arquivos principais
- `index.html` — estrutura da página
- `styles.css` — identidade visual e responsividade
- `script.js` — interações do site
- `assets/` — logo e favicon
- `docs/briefing.md` — briefing consolidado do projeto
- `history/` — prévias e pacotes das versões desenvolvidas durante a construção
